# Zephyr's Enchanting

Zephyr's Enchanting is a mod for Minecraft that overhauls the enchanting system, intoducing a new way of adding enchantments. In your world, you can find items which can be converted into enchantments at the enchanting table, removing much of the randomness from the system and encouraging exploration.

You can download the mod on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/zephyrs-enchanting).
